# Daily Note 📔

Минималистичный цифровой дневник и ежедневный планировщик, который помогает отслеживать настроение, фиксировать мысли и управлять задачами в одном красивом месте.

![Daily Note Interface](screenshot.png)

## ✨ Особенности

- **📝 Ежедневные записи** - Записывайте свои мысли, идеи и благодарности
- **😊 Трекер настроения** - Оценивайте день по 5-балльной шкале
- **✅ Управление задачами** - Планируйте и отслеживайте ежедневные задачи с визуализацией прогресса
- **🔥 Счётчик серий** - Формируйте привычку вести дневник регулярно
- **💾 Автосохранение** - Никогда не потеряете свои мысли благодаря автоматическому сохранению
- **🎨 Настройка внешнего вида** - Светлые/тёмные темы, выбор шрифта, фоновые узоры
- **🌍 Мультиязычность** - Русский, English, Беларуская, Українська, Deutsch, Français, Español
- **📊 Статистика** - Отслеживайте свой прогресс во времени
- **😴 Трекер сна** - Отслеживайте качество и продолжительность сна
- **🔒 PIN-защита** - Защита данных PIN-кодом при входе
- **📤 Экспорт данных** - Экспорт в Markdown и JSON
- **🔍 Поиск по архиву** - Быстрый поиск по всем записям, задачам и тегам
- **🎤 Голосовой ввод** - Диктовка текста заметок
- **📷 Фото к записям** - Добавляйте до 6 фотографий к каждой записи
- **⏰ Напоминания** - Браузерные уведомления в выбранное время
- **👤 Профили пользователей** - Персонализируй свой профиль: баннер, аватар (эмодзи или своё фото), описание и статус
- **🤝 Социальная сеть** - Добавляй друзей по уникальному коду, принимай заявки, просматривай профили
- **🏆 Бейджи достижений** - Автоматические награды за серии, количество записей и активность
- **📡 Живые статусы** - Делись тем, чем занят: играешь, работаешь, слушаешь музыку — или свой текст
- **🖼️ Кастомные изображения** - Загружай свои баннеры и аватарки с автоматическим сжатием
- **👁️ Просмотр профилей друзей** - Кликай по другу и смотри его полную страницу: баннер, аватар, био, статус

## 🚀 Быстрый старт

### Требования

- Node.js 18+ 
- npm или yarn

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/Mieqk/Daily-Notes.git

# Перейдите в директорию проекта
cd daily-note

# Установите зависимости
npm install

# Запустите сервер разработки
npm run dev
```

### Сборка для продакшена

```bash
npm run build
```

Собранные файлы появятся в папке `dist/`.

## 🛠️ Технологический стек

- **Frontend:** React 18 + TypeScript
- **Styling:** Tailwind CSS
- **State Management:** React Hooks (useState, useStored)
- **Storage:** LocalStorage
- **Build Tool:** Vite
- **Charts:** Recharts

## 📖 Использование

### Дейли ноут (Daily Note)

1. **Оцените день** - Выберите настроение с помощью эмодзи-шкалы (5 уровней)
2. **Запишите мысли** - Ведите дневник, фиксируйте идеи, итоги дня, благодарности
3. **Добавьте задачи** - Создайте список дел на день с отслеживанием выполнения
4. **Примените шаблон** - Используйте готовые шаблоны: Работа, Отдых, Творчество
5. **Добавьте теги** - Категоризируйте записи хештегами
6. **Прикрепите фото** - Добавьте до 6 изображений к записи
7. **Голосовой ввод** - Надиктуйте текст вместо набора

### 👥 Профили и друзья

#### Мой профиль
1. **Открой профиль** - Нажми на аватарку в правом верхнем углу → «Мой профиль»
2. **Баннер** - Загрузи своё изображение (автоматически обрезается до 3:1) или оставь градиент
3. **Аватар** - Выбери эмодзи из 12 вариантов ИЛИ загрузи своё фото (квадрат 256px)
4. **Имя** - Впиши, как тебя видят друзья (до 40 символов, автосохранение через 0.8 сек)
5. **Био** - Короткое описание: чем живёшь, что любишь (до 140 символов)
6. **Статус** - Выбери пресет (🎮 Играю, 💻 Работаю, 😴 Сплю, 🎧 Слушаю музыку, ✨ Хорошее настроение, 🏃 Активен) или напиши свой
7. **Код друга** - 6-значный уникальный код для добавления друзей (копируется одним нажатием)

#### Друзья (вкладка слева)
1. **Мой код** - Поделись своим кодом с друзьями, чтобы они могли тебя добавить
2. **Добавить друга** - Введи 6-значный код друга и отправь запрос
3. **Входящие заявки** - Принимай или отклоняй запросы на дружбу
4. **Список друзей** - Смотри всех друзей с аватарами, био и статусами
5. **Просмотр профиля друга** - Кликни по другу, чтобы открыть его полную страницу
6. **Удаление** - Подтверждение перед удалением из друзей (случайно не удалишь)

#### Бейджи достижений
- 🌱 **Первооткрыватель** - Создай аккаунт
- 🔥 **Серия 3+** - Веди дневник 3+ дня подряд
- ✍️ **10+ записей** - Напиши 10 или больше заметок
- 🤝 **Есть друзья** - Добавь первого друга

Бейджи автоматически отображаются в твоём профиле и видны друзьям.

## 📱 Установка на телефон (PWA)

Daily Note распространяется как **PWA (Progressive Web App)** — приложение устанавливается прямо из браузера, без App Store и Google Play. Выглядит и работает как обычное приложение: иконка на домашнем экране, отдельное окно, офлайн-режим.

**Ссылка на приложение:** https://daily-notes-io.vercel.app/

### 🍏 iPhone и iPad (Safari)

1. Откройте ссылку в **Safari** (важно: именно Safari, не Chrome!)
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх)
3. Пролистайте вниз и выберите **«На экран "Домой"»**
4. Нажмите **«Добавить»**

Иконка Daily Note появится на домашнем экране рядом с остальными приложениями.

### 🤖 Android (Chrome)

1. Откройте ссылку в **Chrome**
2. Нажмите **меню** (три точки в правом верхнем углу)
3. Выберите **«Добавить на главный экран»** или **«Установить приложение»**
4. Подтвердите установку

### 💻 Компьютер (Chrome / Edge)

1. Откройте ссылку в Chrome или Edge
2. Нажмите на значок установки в адресной строке (или меню → **«Установить Daily Note»**)
3. Приложение откроется в отдельном окне, без вкладок браузера

### ✨ Что вы получаете

- 🏠 **Иконка на домашнем экране** - как у обычного приложения
- 📴 **Офлайн-режим** - записи доступны без интернета
- 🔄 **Автообновление** - приложение обновляется само при выходе новых версий
- 🔒 **Приватность** - данные хранятся локально на вашем устройстве

> **Примечание:** при первом запуске нужен интернет, чтобы приложение закэшировалось. После этого Daily Note открывается даже в авиарежиме.

### Статистика

- График настроения по дням
- Корреляция настроения и выполненных задач
- Тепловая карта продуктивности (16 недель)
- Общая статистика: записи, задачи, слова, серии

### Заметки (Архив)

- Поиск по всем записям
- Фильтрация по тегам
- Просмотр истории дней

### Настройки

- **Тема оформления:** Светлая, Ночная, Океан, Лаванда, Вишня
- **Язык интерфейса:** 7 языков на выбор
- **Шрифт записей:** Основной, Книжный, Моноширинный
- **Размер текста:** 3 уровня масштаба
- **Фоновый узор:** Точки, Сетка, Бумага, Космос, Линии, Гексагон, Волны
- **Эмодзи настроения:** Настройте свои эмодзи для каждого уровня
- **PIN-код:** Включите защиту при входе
- **Экспорт данных:** Скачайте все данные в Markdown или JSON
- **Очистка:** Полное удаление всех данных

## 🔐 Приватность

Все данные хранятся **только локально** в вашем браузере (LocalStorage). Никакая информация не отправляется на серверы или третьим лицам. Вы полностью владеете своими данными.

- PIN-код хешируется и хранится только в браузере
- Экспорт данных позволяет сделать резервную копию
- Полная очистка данных доступна в настройках
- Статусы, био и коды друзей синхронизируются между устройствами
- Ты можешь удалить свой профиль и все данные в любое время
