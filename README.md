# Daily Note 📔

Минималистичный цифровой дневник и ежедневный планировщик, который помогает отслеживать настроение, фиксировать мысли и управлять задачами в одном красивом месте.

![Daily Note Interface](main.png)

## ✨ Особенности

- **📝 Ежедневные записи** - Записывайте свои мысли, идеи и благодарности
- **😊 Трекер настроения** - Оценивайте день по 5-балльной шкале
- **✅ Управление задачами** - Планируйте и отслеживайте ежедневные задачи с визуализацией прогресса
- **🔥 Счётчик серий** - Формируйте привычку вести дневник регулярно (честная серия: день засчитывается, только если заметка создана в этот день)
- **💾 Автосохранение** - Никогда не потеряете свои мысли благодаря автоматическому сохранению
- **🎨 Настройка внешнего вида** - Светлые/тёмные темы, выбор шрифта, фоновые узоры
- **🌍 Мультиязычность** - Русский, English, Беларуская, Українська, Deutsch, Français, Español
- **📊 Статистика** - Отслеживайте свой прогресс во времени
- **😴 Трекер сна** - Отслеживайте качество и продолжительность сна
- **🔒 PIN-защита** - Защита данных PIN-кодом при входе
- **📤 Экспорт данных** - Экспорт в Markdown и JSON
- **🔍 Поиск по архиву** - Быстрый поиск по всем записям, задачам и тегам
- **🎤 Голосовой ввод** - Диктовка текста заметок
- **📷 Фото к записям** - Добавляйте до 6 фотографий к каждой записи
- **⏰ Напоминания** - Браузерные уведомления в выбранное время
- **🌙 Умный сон** - Часы считаются автоматически из «лёг/встал» (включая переход через полночь), качество оценивается автоматически из часов и просыпаний, блокнот сновидений, история по дням и быстрые кнопки 🌙/️
- **🎲 Факт дня** - Живой интересный факт на твоём языке (генерируется Gemini на сервере, кэшируется на день, есть офлайн-коллекция на случай отсутствия сети)
- **🔄 Синхронизация между устройствами** - Аккаунт (почта или Google), данные и настройки синхронизируются в реальном времени через Supabase Realtime; без аккаунта — полностью локальный режим
- **👤 Профили пользователей** - Персонализируй свой профиль: баннер, аватар (эмодзи или своё фото), имя, описание (био) и живой статус
- **🖼️ Кастомные изображения** - Загрузка своих баннеров и аватарок с автоматическим кропом и сжатием на устройстве (экономит трафик и хранилище)
- **📡 Живые статусы** - Пресеты (🎮 Играю, 💻 Работаю, 😴 Сплю, 🎧 Слушаю музыку, ✨ Хорошее настроение, 🏃 Активен) или свой текст — друзья видят твой статус
- **🤝 Друзья** - Добавление по 6-значному коду друга, входящие заявки, список друзей, удаление с подтверждением
- **👁️ Просмотр профилей** - Полноэкранные страницы: свой профиль со всем редактором и профиль друга (баннер, аватар, био, статус, «в друзьях с…»)
- **🏆 Бейджи достижений** - 🌱 Первооткрыватель, 🔥 Серия 3+, ✍️ 10+ записей, 🤝 Есть друзья — начисляются автоматически и видны друзьям
- **📱 Мобильная версия** - Нижняя навигация на 6 вкладок, свайпы между днями, safe-area, установка как PWA

## 🚀 Быстрый старт

### Требования

- Node.js 18+ 
- npm или yarn

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/Mieqk/Daily-Notes.git

# Перейдите в директорию проекта
cd daily-note

# Установите зависимости
npm install

# Запустите сервер разработки
npm run dev
```

### Сборка для продакшена

```bash
npm run build
```

Собранные файлы появятся в папке `dist/`.

### Переменные окружения (для синхронизации)

Без них приложение работает в локальном режиме — всё функционально, данные хранятся в браузере.

```
VITE_SUPABASE_URL=https://YOUR-PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR-ANON-KEY
```

## 🛠️ Технологический стек

- **Frontend:** React 18 + TypeScript
- **Styling:** Tailwind CSS
- **State Management:** React Hooks (useState, useStored)
- **Storage:** LocalStorage (локальный режим) + Supabase Postgres/Storage (аккаунт)
- **Sync:** Supabase Realtime (postgres_changes)
- **Auth:** Supabase Auth (почта + Google OAuth)
- **AI:** Vercel Serverless + Gemini (факт дня)
- **Build Tool:** Vite
- **Charts:** Recharts

## 📖 Использование

### Дейли ноут (Daily Note)

1. **Оцените день** - Выберите настроение с помощью эмодзи-шкалы (5 уровней)
2. **Запишите мысли** - Ведите дневник, фиксируйте идеи, итоги дня, благодарности
3. **Добавьте задачи** - Создайте список дел на день с отслеживанием выполнения
4. **Примените шаблон** - Используйте готовые шаблоны: Работа, Отдых, Творчество
5. **Добавьте теги** - Категоризируйте записи хештегами
6. **Прикрепите фото** - Добавьте до 6 изображений к записи
7. **Голосовой ввод** - Надиктуйте текст вместо набора

### 😴 Сон

1. **Лёг и встал** - Укажите время отхода ко сну и подъёма — часы посчитаются сами, даже если вы спали через полночь
2. **Быстрые кнопки** - 🌙 ставит «лёг» сейчас, ☀️ — «встал» сейчас
3. **Просыпания** - Отметьте, сколько раз просыпались — качество пересчитается автоматически
4. **Качество** - Можно оставить автооценку или поставить свою (Отлично/Хорошо/Нормально/Плохо)
5. **Блокнот снов** - Записывайте сны в отдельное поле
6. **История** - Полоски по дням + список последних записей с деталями

### 🎲 Факт дня

- Карточка факта подстраивается под стиль приложения и текущий язык
- Кнопка 🎲 меняет факт на новый
- Факт кэшируется на день и язык; при отсутствии сети показывается факт из встроенной коллекции

### 👥 Профили и друзья

#### Мой профиль (аватар справа сверху → «Мой профиль»)
1. **Баннер** - Загрузи своё изображение (кроп 3:1 до 1280px) или оставь градиент
2. **Аватар** - 12 эмодзи ИЛИ своё фото (квадрат 256px, webp)
3. **Имя** - До 40 символов, автосохранение при вводе
4. **Био** - «Пара слов о себе» до 140 символов со счётчиком
5. **Статус** - Пресет или свой текст; виден друзьям везде
6. **Код друга** - Уникальные 6 символов, копирование в один тап
7. **Сводка** - Серия и число заметок, бейджи достижений

#### Друзья (вкладка слева)
1. **Мой код** - Плашка с кодом для шаринга прямо во вкладке
2. **Добавить** - Введи код друга → «Найти» → «Отправить запрос»
3. **Заявки** - Принять/отклонить; клик по человеку открывает его профиль
4. **Список** - Аватар, имя, статус или био, счётчик друзей
5. **Профиль друга** - Полная страница: баннер, аватар, био, статус, «в друзьях с…», удаление с подтверждением

#### Бейджи
- 🌱 **Первооткрыватель** - есть у всех с профилем
- 🔥 **Серия 3+** - три дня записей подряд
- ✍️ **10+ записей** - десять и больше заметок
- 🤝 **Есть друзья** - первый друг

### 📱 Жесты и мобильные

- Свайп влево/вправо в «Дейли ноут» листает дни
- Нижняя навигация: Дейли, Стата, Заметки, Сон, Друзья, Настройки
- Установка на домашний экран как обычное приложение (PWA)

### Статистика

- График настроения по дням
- Корреляция настроения и выполненных задач
- Тепловая карта продуктивности (16 недель)
- Общая статистика: записи, задачи, слова, серии

### Заметки (Архив)

- Поиск по всем записям
- Фильтрация по тегам
- Просмотр истории дней

### Настройки

- **Тема оформления:** Светлая, Ночная, Океан, Лаванда, Вишня
- **Язык интерфейса:** 7 языков на выбор
- **Шрифт записей:** Основной, Книжный, Моноширинный
- **Размер текста:** 3 уровня масштаба
- **Фоновый узор:** Точки, Сетка, Бумага, Космос, Линии, Гексагон, Волны
- **Эмодзи настроения:** Настройте свои эмодзи для каждого уровня
- **PIN-код:** Включите защиту при входе
- **Экспорт данных:** Скачайте все данные в Markdown или JSON
- **Очистка:** Полное удаление всех данных

## 📱 Установка на телефон (PWA)

Daily Note распространяется как **PWA (Progressive Web App)** — приложение устанавливается прямо из браузера, без App Store и Google Play. Выглядит и работает как обычное приложение: иконка на домашнем экране, отдельное окно, офлайн-режим.

**Ссылка на приложение:** https://daily-notes-io.vercel.app/

### 🍏 iPhone и iPad (Safari)

1. Откройте ссылку в **Safari** (важно: именно Safari, не Chrome!)
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх)
3. Пролистайте вниз и выберите **«На экран "Домой"»**
4. Нажмите **«Добавить»**

Иконка Daily Note появится на домашнем экране рядом с остальными приложениями.

### 🤖 Android (Chrome)

1. Откройте ссылку в **Chrome**
2. Нажмите **меню** (три точки в правом верхнем углу)
3. Выберите **«Добавить на главный экран»** или **«Установить приложение»**
4. Подтвердите установку

### 💻 Компьютер (Chrome / Edge)

1. Откройте ссылку в Chrome или Edge
2. Нажмите на значок установки в адресной строке (или меню → **«Установить Daily Note»**)
3. Приложение откроется в отдельном окне, без вкладок браузера

### ✨ Что вы получаете

- 🏠 **Иконка на домашнем экране** - как у обычного приложения
- 📴 **Офлайн-режим** - записи доступны без интернета
- 🔄 **Автообновление** - приложение обновляется само при выходе новых версий
- 🔒 **Приватность** - данные хранятся локально на вашем устройстве

> **Примечание:** при первом запуске нужен интернет, чтобы приложение закэшировалось. После этого Daily Note открывается даже в авиарежиме.

## 🔐 Приватность

Все данные хранятся **только локально** в вашем браузере (LocalStorage). Никакая информация не отправляется на серверы или третьим лицам. Вы полностью владеете своими данными.

- PIN-код хешируется и хранится только в браузере
- Экспорт данных позволяет сделать резервную копию
- Полная очистка данных доступна в настройках

### Синхронизация и аккаунт (опционально)

Если войти в аккаунт, данные шифрованно хранятся в Supabase и доступны только вам:

- Row Level Security: чужие записи, задачи и сон никто прочитать не может
- Профиль (имя, био, статус, код друга) виден только друзьям и тем, кто знает код
- Кастомные аватары и баннеры лежат в Supabase Storage; перезаписать или удалить файл может только владелец
- Локальный режим остаётся доступным всегда — аккаунт не обязателен
